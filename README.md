## ✨ Overview

**Lily Pond** is an interactive browser art simulation inspired by Claude Monet's water garden at Giverny. Step into a tranquil virtual sanctuary where Nishikigoi (koi) glide peacefully beneath floating lily pads, playful frogs hop between blossoms, and an elusive turtle rises periodically to breathe.

## 🌿 Highlights & Features

- **Interactive Fluid Water Ripples:** Glide your cursor or touch the surface to cast real-time water wavelets and light refractions.
- **Living Ecosystem AI:**
  - **Koi Fish (Nishikigoi):** Smooth procedural boid swimming and feeding behaviors.
  - **Frogs:** Jump and perch onto lotus pads.
  - **Pond Turtle:** Quietly surfaces for air and submerges back into the tranquil deep.
- **Feed Interaction:** Toggle the **feed** mode to scatter nutrient pellets across the pond water and watch creatures dart to feed.
- **Diurnal Lighting Cycle:**
  - **Dawn:** Soft apricot morning light.
  - **Day:** Bright sunlit clarity with shimmering water caustics.
  - **Dusk:** Atmospheric amethyst sunset hues.
  - **Dark:** Calming midnight shadows and moonlit glimmers.
- **Full SEO & Open Graph Ready:** Configured with Schema.org JSON-LD, rich Twitter Cards, Open Graph tags, canonical URLs, and sitemap for search indexing.

## 🚀 Quick Start / Local Development

Clone the repository and serve locally:

```bash
git clone https://github.com/jinanshm/lily-pond.git
cd lily-pond
```

Open `index.html` directly in any modern browser, or launch a local server:

```bash
# Python
python -m http.server 8000

# or Node / npx
npx serve .
```

Visit `http://localhost:8000` to enjoy the pond.
